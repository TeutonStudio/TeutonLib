# TeutonLib

TeutonStudio’s shared Minecraft library for computer UI and APIs, Create/Sable integration, hybrid trains, physical hoses, energy and compatibility fixes. **SableSchlauch and CreateSableOptimization are included**; remove their separate JARs.

Requires **Minecraft 1.21.1**, **NeoForge 21.1.234+**, **Java 21** and **KotlinForForge 5.11.0–<6** on server and clients. Optional integrations have their own version requirements.
